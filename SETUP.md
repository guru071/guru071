# GOAT'ECH GitHub Profile

## Installation

1. Create/open the GitHub repository named `guru071` (the profile repository for the account).
2. Copy `README.md` and the the image/SVG files into the repository.
3. Commit and push.
4. GitHub will render the README automatically on the profile page.

The main portrait is `profile.jpg`. The animated visual assets are SVGs and require no external CSS file.

The design uses a black/gold visual language inspired by the current GOAT'ECH website's professional technology aesthetic.
